# Aayan Makandar — Portfolio

This is a self-contained static portfolio website prepared for GitHub Pages.

## Run locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Create a new public repository on GitHub, for example `aayan-portfolio`.
2. Upload `index.html` and this `README.md` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait for GitHub Pages to deploy. Your site URL will be shown in the Pages section, usually:
   `https://YOUR-USERNAME.github.io/aayan-portfolio/`

## Important notes
- This is a static HTML site; GitHub Pages can host it without a backend.
- The website's editor stores changes in that browser's `localStorage`. Those edits do not automatically update the GitHub repository or sync across devices.
- The editor passcode is embedded in the HTML source, so it is not secure authentication. Do not use it to protect private information.
- If you want to use a custom domain or publish from your profile repository, configure that in **Settings → Pages**.
